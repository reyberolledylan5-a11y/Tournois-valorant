Admin Valorancia

Modifie les équipes, leurs joueurs, leur elo et leur peak. Ensuite, génère le nouveau fichier data.js et colle-le sur GitHub : le site se met à jour tout seul.

Calendrier des matchs

Ajoute les matchs avec le jour, l'heure et les deux équipes. Un message « À vérifier » apparaît si une équipe n'est pas disponible à cette heure ou si elle a déjà un match qui se chevauche.

Nouveau fichier data.js

  1. Clique sur « Copier » (ou « Télécharger »).
  2. Sur GitHub, ouvre ton dépôt puis le fichier data.js, et clique sur le crayon.
  3. Sélectionne tout le contenu, colle le nouveau, puis clique sur « Commit changes ».
  4. Netlify republie le site en une minute environ.
